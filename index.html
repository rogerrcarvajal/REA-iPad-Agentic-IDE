⚙️ Cuenta, modelos y credenciales

🔐 Cuenta Google

Usa tu cuenta Google para llamar a la API de Gemini con la cuota de tu proyecto de Google Cloud (nivel gratuito o de pago). Requiere un OAuth Client ID tipo "Aplicación web" y que el IDE se sirva por HTTPS o localhost.

🔑 API key de Gemini (Google AI Studio)

La forma más directa (funciona por HTTP en la LAN): crea una key gratis en aistudio.google.com/apikey. Si tu proyecto tiene facturación, usa los límites de pago.

🌿 Git

Token fine-grained con permiso Contents: Read and write. Se guarda solo en este dispositivo.

🖥️ Terminal PC (puente XAMPP)

Permite ejecutar CLIs reales del PC (git, npm, gemini -p, ollama run) desde el iPad. En el PC copia api/config.example.php a api/config.local.php y define bridge_token.
